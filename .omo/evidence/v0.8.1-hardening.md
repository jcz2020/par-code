## P1 fixes

- Plan submission overwrites the draft written by `write_plan_file`, so a plan turn leaves one file (live: `append-gamma-to-seed.md` only).
- The post-turn auto-persist is skipped when a plan was submitted, so no wrap-up file.
- `par session fork` ids resolve by an 8-char prefix: `resolve_id` queries `conversations` instead of the events join.
- UTF-8-safe title truncation (`truncate_utf8`) used by session list/show, memory summaries and delegation previews; `par session list`/`show`/`memory list` now decode as valid UTF-8.
- `apply_patch` tool description + default prompt state the `diff --git` requirement for multi-file patches.
- `/dev/null`, `/dev/stdin`, `/dev/stdout`, `/dev/stderr` are ignored by the path classifier.
- Ctrl+C during streaming raises from the chunk callback (REPL-side workaround), stops the stream on the next chunk, and renders `[cancelled by user]`; the session stays usable.
- `--db-uri` now reaches the persistence service (`to_persistence_config`, `make_persistence_service`).
